# IoT-Based Automatic Rain Detector for Clothes Protection

## Overview
An IoT-based smart automation system developed using Arduino Uno, rain sensor, and servo motor to automatically protect clothes from unexpected rainfall.

## Technologies Used
- Arduino Uno
- Rain Sensor
- Servo Motor
- Embedded C/C++
- IoT

## Features
- Automatic rain detection
- Servo motor automation
- Smart clothes protection
- Low-cost embedded system

## Working
The rain sensor detects rainfall and sends signals to the Arduino Uno. The Arduino automatically activates the servo motor to deploy a protective cover over clothes.

## Applications
- Smart homes
- Household automation
- Agricultural protection systems
